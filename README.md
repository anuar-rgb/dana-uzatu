# Дана — Ұзату той

Сайт-приглашение на ұзату той. Статическая страница, свёрстана по макету Figma
(«QYZ UZATY», 430 × 4443), публикуется через GitHub Pages.

**Адрес:** https://anuar-rgb.github.io/dana-uzatu/

## Что где лежит

| Путь | Содержимое |
|---|---|
| `index.html` | разметка и тексты приглашения |
| `css/style.css` | оформление |
| `js/main.js` | календарь, обратный отсчёт, музыка, сауалнама |
| `assets/images/` | фото, орнаменты, рваный край бумаги |
| `assets/music/` | фоновая мелодия |

## Как поменять данные

Всё, что меняется чаще всего, собрано в объекте `CONFIG` в начале `js/main.js`:

- `eventDate` — дата и время тоя (влияет на обратный отсчёт);
- `calendar` — месяц и выделенный день в календаре;
- `mapUrl` — ссылка на точку в 2ГИС;
- `whatsappPhone` — номер, на который уходят ответы гостей.

Тексты приглашения правятся прямо в `index.html`.
